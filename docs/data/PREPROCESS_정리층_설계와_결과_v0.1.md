# 정리 층(전처리) 설계와 결과 (v0.1)

> 2팀 · 2026-11-24 · 대상: 기업마당 1,294건, K-Startup 3,822건(접수 시작일 기준 최근 1년 3,819건 + 모집 중 3건)
> 수치는 `tools/preprocess_notices.py`를 실행해 센 값이다. 정리 결과는 **로컬 전용**(`data/cleaned/`, Git 제외)이다.

## 1. 결론

- 두 포털의 원본에서 **공통 스키마의 정리 층을 만들었다**: 공고 5,116건, 검색 청크 32,930개.
- 정리는 **되돌릴 수 있는 것만** 했다(줄바꿈·HTML 엔티티·공백, 필드 이름·ID, 기관명 분리, 날짜 형식, 상태). 나이·업력·업종 값의 정규화와 요건 승인은 하지 않았다(골든셋 뒤).
- K-Startup은 동료 정리본이 아니라 **원본에서 다시 정리**했고, 정리본과 원본의 텍스트·URL이 공백·엔티티 차이를 빼고 같은지 30,576개 필드로 검사해 **불일치 0**이다.

## 2. 입력과 규칙

| 항목 | 내용 |
|---|---|
| 기업마당 | `data/bizinfo/parsed/20261124_091601`(파싱 결과) + 로컬 첨부 추출 텍스트. 제목은 API 원본(`pblancNm`)을 `title_raw`로 보존 |
| K-Startup | `data/kstartup/raw/20261124_full`(전체 30,632건을 받은 원본)에서 접수 시작일 2025-11-24 이후 3,819건 + **모집 중이면 시작일과 무관하게 포함**(3건 추가) |
| 멱등성 | 같은 입력이면 같은 결과. 입력은 건드리지 않고 새 폴더에만 쓴다 |
| 연락처 | 공공기관 연락처는 가리지 않는다(팀 결정). `[REDACTED…]` 대체 문자열 0건 |
| 첨부 | 기업마당 본문출력파일의 자격·제외·기준·혜택·기간·방법 구간만 청크로 만든다. K-Startup은 API에 첨부 칸이 없고 `robots.txt`가 경로를 금지해 없음 |

### 정리 규칙과 하지 않은 것

| 구분 | 한 것 | 하지 않은 것 |
|---|---|---|
| 텍스트 | CRLF→LF, HTML 엔티티 해제(`&amp;`→`&`), NBSP·0폭 문자 제거, 줄 끝 공백 제거, 3줄 이상 빈 줄 축소 | 문장 수정, 요약, 번역, 오타 교정 |
| ID·버전 | `notice_id`(`BIZINFO:…`·`KSTARTUP:{pbanc_sn}`), `fetched_at`, `version`, `is_latest`, `content_hash`, `raw_hash` | |
| 날짜·상태 | `YYYYMMDD`→ISO, 마감 `23:59:59+09:00`, `period_status`(마감 있는 모집 중 / 날짜 없는 모집 중 / 종료) | 날짜 없는 공고를 임의로 마감 처리 |
| 기관 | K-Startup 기관 문자열을 쉼표로 나눠 `org_names`, 끝 단어가 직함이면 `org_role_titles`로 분리, 원문은 `org_raw` | 기관 동일성 판단(`SAME_AS_CANDIDATE`) |
| 지역 | K-Startup 약칭→코드 사전, 기업마당은 소관 기관이 시도일 때만 코드. 해시태그는 `region_tags_hint`로만 보존 | 해시태그를 지역 근거로 사용 |
| 구조화 값 | `business_age_raw`, `founder_age_raw`, `applicant_target_raw` 원문 문자열 보존 | 숫자 조건으로 확정, 옵션 관계(AND/OR) 결정 |
| 재공고·연장 | 제목·기관이 비슷한 공고 묶음 **후보 ID**(`related_group_id`)와 신호(연장·재공고) | `SUPERSEDES` 확정 |
| 첨부 URL | 형식이 깨진 안내 URL에 `guide_url_malformed` 표시 | URL 수정 |

### 연결 확인
`tools/graphrag/`의 엔진이 이 정리 층을 읽도록 연결했다(`Engine()`은 `data/cleaned`가 있으면 그것을 쓴다). 단위 시험(graphrag 21개, 전처리 11개)이 통과했고, SQL 베이스라인 비교는 300개 프로필·모집 중 1,452건에서 불일치 0이다.

## 4. 20건 눈 확인(무작위, 두 포털 10건씩)과 발견한 점
- 날짜·기관·지역 코드·모집 상태가 원문과 맞았다.
- **기업마당 지역:** 소관 기관이 중앙부처인 공고는 제목에 `[경북]`, `[울산]`이 있어도 지역 코드가 비어 있다(10건 중 4건, 전체 330건). 제목 접두를 근거로 쓸지는 별도 결정이 필요하다(`[광주]` 공고의 광주/전남 구분과 같은 문제).
- **기업마당 마감일:** 날짜가 있는 공고는 일부이고 나머지는 `OPEN_NO_DATE_DEADLINE`이다.
- 눈으로 본 표본이 작아 이 점검은 정확도 지표가 아니다.

## 5. 한계
- 기관 직함 분리는 "마지막 단어가 직함으로 끝나면" 규칙이라 `생명공학창업보육센터장`처럼 부서명이 붙은 경우 부서명이 직함으로 분류된다. 검토 CSV로 확인해야 한다.
- 재공고·연장 묶음은 제목 유사도 후보이며 틀린 묶음(같은 기관의 다른 사업)이 섞일 수 있다.
- K-Startup 본문 요건은 API 문구뿐이다(제외 요건 필드 비어 있음, 첨부 없음).
- 기업마당 일반 첨부 1,360개는 아직 받지 않아 청크에 없다.
- 지역 값을 가져온 원천 필드는 `region_source`(`supt_regin`·`jurisdiction_org_sido`·없음)다. 2026-11-25에 `region_basis`에서 이름을 바꿨다(설계서의 `region_basis`는 판단 기준을 뜻한다).
- 정리 층은 정규화 확정값을 담지 않는다. 지역·업력·연령 조건은 `tools/graphrag/cleaned.py`가 원문 문자열에서 읽는다.

## 6. 실행

```powershell
python tools/preprocess_notices.py          # data/cleaned/<날짜>/ 생성
python tools/test_preprocess.py             # 단위 시험 11개
python tools/test_graphrag.py               # 평가기 시험 21개(정리 층 연결 후에도 통과)
```
