## 0. 결론

형식과 참조 무결성은 정상이다. v2 대비 **새로 들어온 것은 기업마당 PDF 추출 필드와 K-Startup 업력·연령 분리 필드**이고, v2에서 지적한 메타 층 문제는 거의 그대로다. 새 PDF 텍스트가 청크에 섞여 노이즈가 생겼다. 지역 오분류는 **원본 해시태그가 지역 한정 공고에도 지역 17개를 전부 다는 경우(전체의 27%)** 때문에 생기는 것으로 보이지만, 30건이 모두 `전국`인 것은 이 비율로 설명되지 않아 원인은 확정하지 못했다. 어느 쪽이든 해시태그만으로 `전국`을 판정하면 안 된다. 아래 §3 정리 후 적재를 권한다.

## 3. 새로 생긴 문제

| # | 우선순위 | 문제 | 근거 | 요청 |
|---|---|---|---|---|
| 1 | 높음 | PDF 추출 텍스트가 청크 본문에 섞임 | 기업마당 청크 길이 중앙값 470→1,267자, 최대 3,156자. 19건에 "자동 추출 후보(검토 필요)" 문구가 들어감 | 청크 본문(`chunk_text`)에는 넣지 말고 별도 필드·청크로 분리. 검토 완료 전 값은 임베딩하지 않는다 |
| 2 | 높음 | 지역 판정 규칙 | 해시태그 17개 전부 → `전국` 규칙이 오분류를 만든다(§2 #1) | 해시태그가 아니라 본문·`jrsdInsttNm`·PDF `region_requirements`로 판정하고, 근거가 없으면 `unknown`으로 둔다. 오분류된 `전국` 연결은 제거 |
| 3 | 중간 | 노이즈 텍스트가 요건 필드로 분류됨 | 방송광고 공고(`BIZINFO:PBLN_000000000117985`)의 `eligibility` 구간이 "개정 2019. 1. 1 시행…" 개정 이력과 서로 다른 조항이 뒤섞인 글이다(개정 이력 문구 포함 1건) | 개정 이력·서식 문구를 걸러내거나 검토 큐 우선 대상으로 표시 |
| 4 | 중간 | 출처 표기가 섞임 | `application_period` 항목의 `source_type`이 `BIZINFO_API`인데 `source_file`은 `bizinfo_30_raw.json`이고 `page`(10쪽)가 붙어 있다(20건) | API 값에는 `page`를 두지 않고, PDF 값과 `source_type`을 구분 |
| 5 | 중간 | 필드와 JSON 불일치 | 구미시 공고 JSON에는 `required_location: 구미시 소재`가 있는데 `region_requirements_text`는 비어 있다. 이 필드는 기업마당 30건 모두 비어 있다 | JSON에서 파생되는 평문 필드를 같이 채우거나, 필드를 없앤다 |
| 6 | 중간 | PDF 내려받기 이용 조건 | 파일명·쪽수 단위 본문이 들어 있어 첨부를 내려받은 것으로 보인다. 앞서 "이용 조건 확인 후"로 했다 | 이용 조건 확인 여부와 PDF 원본 보관 위치를 알려 달라. 원본은 저장소에 넣지 않는다 |

## 4. 요건 층에 주는 의미

- **긍정:** PDF 추출 구조(`value` + `sources` + `fact_status`)가 온톨로지의 `Requirement`·`Condition`과 `evidence`·`review_status`에 가깝다. 요건 추출 입력으로 쓸 수 있다. 다만 `pdf_conditions_json`은 JSON **문자열**이라 파싱이 필요하다.
- **주의:** 추출 항목 대부분이 `needs_human_review`다. 이를 정답 세트로 쓰지 않는다. 정답 세트는 사람이 본문을 읽고 따로 만든 뒤, 이 추출과 비교하는 평가 대상으로 쓴다(추출 결과를 보고 정답을 쓰면 평가가 오염된다).
- **관찰:** 구미시 공고는 본문의 "구미 소재"와 해시태그 전국이 충돌한다. 이는 기초 설계서의 "본문 우선, `source_conflict` 기록" 규칙이 필요한 실제 사례다.

## 5. 한계

- 원본 응답·변환 코드·PDF를 보지 못했다. 추출 정확도는 구미시 1건을 읽어 본 것이고 전체 정확도가 아니다.
- 지역 오분류의 원인은 구미시 추출 메모, manifest 집계, 우리가 직접 받은 API 전량(1,294건)의 태그 분포에서 추정했다. 동료의 원본 응답은 보지 못했다.
- 이용 조건 확인 여부는 동료의 답이 필요하다.
