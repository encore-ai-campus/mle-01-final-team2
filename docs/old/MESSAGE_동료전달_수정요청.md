## 수정 요청 (우선순위 순)

**높음**
1. `eligibility_text` 의미가 소스마다 다릅니다. 기업마당은 `trgetNm`("중소기업" 등), 나라장터는 지역제한 문구, K-Startup은 여러 필드를 이어 붙인 값입니다. 필드를 분리하거나 이름을 바꿔 주세요. 기업마당의 실제 요건은 `summary`의 ☞ 항목에 있으니 청크의 `대상·자격`에는 그쪽을 넣어 주세요.
2. 지역이 관계로 없습니다. 지역 코드표(시도·시군구)를 만들어 공고에 연결해 주세요. 기업마당 해시태그에 지역 17개가 모두 있으면 `전국`으로 정규화해 주세요.
3. `tags`에 지역, 분야, 기관명, 연도가 섞여 있습니다. 지역은 지역 노드로, 분야·기관은 기존 노드와 중복이라 제거하고, 나머지만 키워드로 남겨 주세요.
4. 기관 노드에 `기초자치단체`(범주값)와 `경기도일자리재단 남부사업본부장`(직함 포함)이 있습니다. 범주값은 기관 노드로 만들지 말고 속성으로 두고, 직함은 제거해 주세요.
5. 나라장터 `summary`가 `[1^4320140101^그래픽용어댑터]`라 청크 본문이 거의 비어 있습니다. 기관, 계약방식, 입찰방식, 추정가격, 마감을 문장으로 풀어 넣어 주세요.

**중간**
