# 공고 주제 전환 사전 확인 (2026-11-23)

대안 주제 초안([기획설계] MLE_기획보고서_2팀_공고주제안_초안.md)의 전환 판단에 쓰려고, 공개 페이지만 읽어 확인한 결과이다. **인증키를 발급하거나 API를 호출하지 않았고, 첨부 파일은 내려받지 않았다.** 아래 표본은 작고 치우쳐 있어 결론이 아니라 **판단 재료**이다.

## 1. 요약

| 확인 항목 | 결과 | 상태 |
|---|---|---|
| K-Startup 공고 API 명세 | 응답 필드, 요청 변수, 이용 조건 확인 | 확인함(명세) |
| 기업마당 공고 API 명세 | 요청·응답 필드 확인 | 확인함(명세) |
| 실제 API 호출·응답 | 하지 않음(인증키 없음) | **미확인** |
| 수집 허용 범위(robots.txt) | K-Startup은 공고 목록 HTML과 첨부 경로를 막음. 기업마당은 `/download` 등만 막음 | 확인함 |
| 표본 공고 요건 읽기 | 기업마당 공고 15건(2026-11-20 등록분)의 상세 화면 | 확인함(편향 있음) |
| 첨부 문서 내용 | 열지 않음. 형식(확장자)만 확인 | **미확인** |

**한 줄 판단.** 데이터는 공개 API로 확보할 길이 있고 이용 조건도 막히지 않았다. 그러나 표본으로는 “그래프가 꼭 필요하다”는 근거가 늘지 않았다. 업력·연령처럼 정형 값은(파싱이 되면) SQL로 충분할 가능성이 크고, 그래프가 의미 있는 곳은 소수(법령 정의 연결, 기준일·트랙 같은 정규화)였다.

## 3. 수집 허용 범위

| 사이트 | robots.txt에서 확인한 것 | 영향 |

### 4.1 표본의 성격과 한계

- 기업마당 지원사업 공고 목록에서 **2026-11-20 등록분 15건**(목록 1~15번째)을 읽었다. 무작위 표본이 아니다.

### 4.4 손으로 정규화해 본 사례 (스키마 시험)

초안 §5.1의 요건·조건 구조에 맞춰 3건을 정규화해 보고, **구조가 부족한 곳**을 적었다.

**128046 경북 오아시스 특판전** (자격, AND)

| 조건 | 속성 | 연산 | 값 | 기준일 |
|---|---|---|---|---|
| ① | 사업자등록 주소지 | WITHIN | 경상북도(대상 시군: 경주·구미·의성) | 공고일 |
| ② | 중소기업 또는 소상공인 확인서 발급 가능 여부 | = | 예 | - |
| ③ | 업종 | IS_A | 제조·가공업 | - |
| ④ | 전년도 연 매출 | < | 100억 원 | 전년도 |

- **문제 1(입력 정밀도).** ④는 임계값이 100억 원이다. 초안 NFR-N03은 조건을 범주형으로 받기로 했는데, 구간 경계가 100억과 맞지 않으면 판정이 `확인 필요`가 된다. 정밀 판정과 개인정보 최소화가 충돌한다.
- **문제 2(②).** “확인서 발급 가능”은 사용자가 모르는 값일 수 있어, 중소기업 정의(법령)로 환원해 판정하거나 사용자에게 직접 묻는 항목이 필요하다.

**128057 김해시 맑은공기 패키지** (자격, AND)

| 조건 | 속성 | 연산 | 값 | 비고 |
|---|---|---|---|---|
| ① | 사업장 소재 구역 | WITHIN | 진영읍·부곡동·유하동·지내동·안동의 지정 공업지역(악취관리지역) | 행정구역 코드로 해소 불가 |
| ② | 사업장 종별 | = | 대기환경보전법 시행령 제13조 1~5종 | 정의 노드→법령 |
| ③ | 기업 규모 | IS_A | 중소기업기본법 시행령 제3조제1항의 중·소기업 | 정의 노드→법령(별표 매출 기준 등) |

- **문제 3(지정 구역).** “악취관리지역인 공업지역”은 행정구역 코드표가 아니라 용도지역·관리지역 지정 정보가 필요해 `확인 필요`로 남는다.
- **좋은 사례.** ②·③은 정의→법령 연결의 실제 사례이다. 단, 사용자가 자기 사업장의 “종”을 모를 가능성이 높아 입력 항목 설계가 필요하다.

**추가로 본 구조 문제**

- **트랙.** 128052(GPU)는 산업계·학계·연구계 대상별로 지원 규모가 다르다. 초안의 `Notice` 아래에 **트랙(하위 사업)** 단위가 필요하다.
- **기준일.** 조건마다 기준일(공고일, 접수 마감일, 전년도)이 다르다. `Condition`에 기준일 필드를 둔다.
- **파서.** 첨부의 대부분(13건)이 **hwpx**이다. 기존 HWP5(OLE) 파서는 이 형식을 읽지 못한다(HWPX는 ZIP+XML 형식). 별도 파서가 필요하다.
