# MLE 1기 최종 프로젝트 가이드 핵심 요약

- 원문: [MLE 1기 최종 프로젝트 가이드](https://playdatacademy.notion.site/MLE-1-402d943bcac280d69e20dd11ced779df)
- 확인일: 2026-11-17
- 확인 방법: 사용자가 열어 둔 Chrome의 원문 페이지 열람
- 범위: 프로젝트 목표, 단계별 수행 내용과 필수 산출물, 발표 평가, 팀 운영·멘토링 안내

> 원문의 요구사항을 요약한 문서다. 현재 저장소의 구현 완료 여부를 평가한 문서는 아니다. 원문에 팀 구성은 ‘3팀’, 주제·단계별 목표는 ‘1~5팀’으로 함께 표기되어 있으므로 실제 운영 팀 수와 배정은 운영 매니저 공지를 확인한다.

## 1. 프로젝트의 핵심 목표

**도메인 데이터 분석 → 지식 그래프 구축 → 하이브리드 검색·Multi-hop 추론 → 멀티에이전트 → 대화형 서비스 → 정량 평가·배포**까지 연결한 신뢰형 GraphRAG 서비스를 완성한다.

기능 구현뿐 아니라 데이터·지식 추출의 품질, 답변의 신뢰성과 안전성, 추론 과정의 가시성, 실제 운영 가능성을 평가한다. 프로젝트 중 **최소 1건 이상의 모델 데모를 Hugging Face에 공개**하는 성과지표도 제시되어 있다.

## 2. 팀별 주제

| 팀 | 주제 요약 |
| --- | --- |
| 1팀 | 엔터프라이즈 지식 자산을 탐색·활용하는 GraphRAG 도메인 에이전트 |
| 2팀 | 온톨로지와 Multi-hop 추론을 이용한 기업 규정 준수 검증 |
| 3팀 | 직무 역량 분석 기반 스마트 커리어 매칭·가이드 플랫폼 |
| 4팀 | 대화 데이터·지식 분석 기반 상담 에이전트 |
| 5팀 | 그래프 지식 기반 자율형 업무 자동화 시스템 |

### 3팀의 단계별 목표

- **도메인·그래프 설계:** 직무 역량(Skill)과 커리어 경로 사이의 상관관계를 그래프로 모델링한다.
- **지식 추출·적재:** 채용 공고와 이력서에서 기술 스택을 자동 추출하고 매핑한다.
- **추천 엔진:** 중심성·유사도 등 그래프 알고리즘을 활용해 맞춤형 커리어 경로를 추천한다.
- **최종 서비스:** 공통 평가·안전성·배포 요건을 갖춘 커리어 가이드 서비스를 시연한다.

## 3. 단계별 수행 내용과 필수 산출물

| 단계 | 핵심 수행 내용 | 필수 산출물 |
| --- | --- | --- |
| STEP 1. 기획·설계 | 팀 빌딩·주제 확정, 요구사항·기능 명세, 아키텍처·기술 스택, 일정 수립 | 기획서(요구사항 포함), WBS, 화면 설계서(IA·와이어프레임) |
| STEP 2. 도메인·온톨로지 | 외부 API·공개 데이터 수집, EDA·통계 분석, 엔티티·관계 정의, Neo4j LPG 스키마·속성·제약조건·인덱스·Cypher 설계, Git/GitHub 협업 환경 | 도메인 온톨로지 설계서, Neo4j 그래프 스키마 정의서 |
| STEP 3. 지식 추출·DB 구축 | LangChain 추출 파이프라인, NER·관계 추출용 프롬프트/CoT, S-P-O 트리플 자동 적재, Entity Resolution, 정합성·예외 처리 | 데이터 적재 스크립트 |
| STEP 4. GraphRAG·멀티에이전트 | 벡터+그래프 하이브리드 검색, Multi-hop 추론, 메모리 연동, GDS 추천, 대화형 UI·그래프 시각화, LangGraph 오케스트레이션 | GraphRAG 추론 엔진 및 멀티에이전트 오케스트레이션 엔진 |
| STEP 5. 평가·최적화·배포 | RAGAS 평가·개선, LoRA 파인튜닝, 양자화·vLLM 서빙, Guardrails, Docker·CI/CD·클라우드 배포, Langfuse 운영 모니터링 | 최종 배포 웹 애플리케이션, 성능 평가 보고서 |

원문은 위 산출물을 **필수**로 명시하며, 추가 산출물은 운영 매니저와 소통 후 진행하도록 안내한다.

## 4. 구현·평가에서 놓치기 쉬운 요건

### 데이터·지식 그래프

- 수집·EDA·통계 분석으로 도메인을 정량적으로 이해하고, 인사이트를 보고서에 반영한다.
- 온톨로지의 논리적 타당성과 도메인 요구사항의 부합 여부를 설명한다.
- 노드·엣지뿐 아니라 속성, 제약조건, 인덱스 전략과 탐색용 Cypher를 명시한다.
- 자동 적재 시 Entity Resolution으로 중복을 제어하고 정합성·예외 처리를 구현한다.
- 지식 트리플 품질을 **샘플 정밀도, 온톨로지 스키마 준수율, Entity Resolution 일관성**으로 제시한다.

### 검색·추론·에이전트

- LangChain·neo4j-graphrag 등을 활용해 벡터 검색과 그래프 검색을 연계한다.
- 검색 결과 재구성과 Multi-hop 추론으로 답변 신뢰성을 확보하고, 메모리 관리도 연결한다.
- **슈퍼바이저·계획·자기성찰 에이전트**를 LangGraph로 직접 설계·구현한다.
- 최종 발표에서는 에이전트 **trajectory(도구 선택·step 성공률)** 평가도 요구한다.
- Neo4j GDS의 중심성·유사도 또는 지식 그래프 연계 오케스트레이션 알고리즘의 기술적 타당성을 설명한다.

### 서비스·운영

- Streamlit 또는 유사 프레임워크로 대화형 UI를 구현하고 **토큰 스트리밍(SSE)** 응답을 제공한다.
- 실시간 지식 그래프와 추론 과정 시각화로 답변 근거와 처리 흐름의 가시성을 확보한다.
- **vLLM·모델 양자화**, Docker, CI/CD, 클라우드 배포를 구성한다.
- Langfuse로 실행 흐름을 관찰하고 온라인 지속 평가를 운영한다.

### 성능 보고서

- RAGAS의 **Faithfulness·Answer Relevance** 등 정량 지표와 개선 결과를 제시한다.
- **PEFT(LoRA) 적용 전후**의 소형 LLM 성능을 비교한다.
- NeMo Guardrails 등으로 안전성·보안 제어를 설계하고 검증 결과를 포함한다.
- 답변 품질 외에 지식 트리플 품질과 도메인 분석 결과도 함께 다룬다.

## 5. 발표 평가의 핵심

| 구분 | 중간 발표 | 최종 발표 |
| --- | --- | --- |
| 기획 | 시장·사용자 요구, 실용성, 해결 방법의 타당성·창의성, 경쟁 서비스 대비 차별화 | 같은 기획 기준을 최종 결과물과 연결해 설명 |
| 구현 | 온톨로지·스키마, 트리플 자동 추출·기초 적재, 하이브리드 검색용 데이터 모델을 시연 | 그래프 구축부터 검색·대화형 UI·RAGAS 평가까지 연결하고 팀별 서비스를 정상 시연 |
| 기술 | LPG 모델링, 추출 프롬프트·CoT, Git/GitHub 협업과 설계 산출물의 완결성 | 하이브리드·Multi-hop, GDS/오케스트레이션, 에이전트 trajectory, LoRA·서빙, 정량 평가·피드백, Guardrails, Entity Resolution |
| 발표역량 | 기획·진행현황을 효과적으로 전달하고 논리적으로 질의응답 | 동일 |

최종 발표에서는 **데이터 분석·멀티에이전트·GraphRAG의 서비스 통합**과 **웹 내부의 안정적인 그래프·추론 시각화**를 특히 확인한다.

## 6. 팀 운영·멘토링

- 팀 구성은 주제 선호, 교과목 성취도, 진로 방향, 개인 역할·성향, 협업 스타일, 갈등 예방을 고려한다. 주제 선호 조사는 팀 배정을 위한 것이며, 팀 구성 후 주제를 다시 확정한다.
- 팀 확정 후 변경은 건강·출석 등 특별한 사유를 제외하고 불가하다.
- 진행 순서는 **대주제 확정 → 주제 구체화 → 계획에 따른 수행 → 중간 발표 → 최종 발표**다.
- 팀장은 일정·산출물·지원 요청의 운영 매니저 소통 창구이며, 팀 대시보드에 팀장 역할을 등록한다.
- 멘토링은 **팀당 최대 20시간**이며, 온라인 인정 시간은 오프라인 시간을 초과할 수 없다. 예를 들어 오프라인 5시간+온라인 10시간이면 총 10시간만 인정한다.
- 시작·종료 시 날짜와 시간이 보이는 사진을 남긴다. 온라인은 화면 캡처, 개인별 멘토링은 사람별 전후 증빙을 남긴다.
- 팀장이 멘토와 일정을 협의해 Discord 팀 채널에 공유하고, 질문·자료는 사전에 올린다. 피드백 반영 사항은 대시보드 일일 진행 기록에 남긴다.
- 주 소통·자료 공유는 매니저가 확인할 수 있는 Discord를 사용한다. 이력서 등 개인정보 문서는 공개 채널 대신 멘토와 1:1로 전달한다.
- 종합 관리·평가는 강사가 맡고, 멘토는 기획·기술·일정·산출물·진로에 대한 방향과 피드백을 제공한다. 문제 발생 시 과정 매니저에게 알린다.
- 원문 기준 최종 발표 **1등 팀 상금은 100만 원**이며, 팀장에게 우선 지급한다.
