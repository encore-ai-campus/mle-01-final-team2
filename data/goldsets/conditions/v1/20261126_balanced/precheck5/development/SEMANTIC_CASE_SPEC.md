# 의미 기반 기대 사례 명세

이 문서는 향후 사람 검수와 판정 엔진 구현을 위한 기대 결과다. **전체 신청 가능 여부가 아니라 명시된 조건/논리 범위의 기대값**이다. `UNKNOWN`은 기준이나 지원자 사실을 확인할 수 없다는 뜻이다.

| 번호 | 입력 사실 / 범위 | 기대 결과 |
|---|---|---|
| 1 | 만 40세 이상, 예비창업자 아님 (`177469`의 신청자 AND) | FALSE |
| 2 | 예비창업자 참, 창업 7년 미만 거짓 (`176813`의 신청 유형 OR) | TRUE |
| 3 | 예비창업자 거짓, 창업 7년 미만 참 (`176813`의 신청 유형 OR) | TRUE |
| 4 | 지방 창업보육센터 입주 이력만 있음 (`176813`의 제한 대상 이력 수) | 0건, 해당 제한을 위반하지 않음 |
| 5 | 지방 창업보육센터와 다른 제한 대상 정부센터 이력이 모두 있음 | 제한 대상 이력 수 > 0, 해당 자격 조건 FALSE |
| 6 | 가족친화 문구는 존재하나 실천 충족 근거가 없음 (`118927`) | 가족친화 조건 UNKNOWN |
| 7 | `178507`의 예비창업자, 현재 사업자등록 미완료이나 입주 후 3개월 내 등록 가능 | 현재 등록 미완료만으로 예비창업자 분기 FALSE 처리하지 않음 |
| 8 | `178507` 신청 당시 자격 사실은 충족, 선정 후 주소 이전은 아직 미이행 | 주소 이전 미이행만으로 신청 자격 FALSE 처리하지 않음 |
| 9 | 제한 대상 시설에 실제 중복입주 (`178507`의 해당 제외 범위) | 해당 `EXCLUSION` TRUE |
| 10 | 경기도 사업장 + 비영리 사회적기업 (`118182`의 명시된 논리 범위) | 해당 지역·유형·영리 여부 구조 TRUE |
| 11 | 경기도 사업장 + 비영리 예비사회적기업 | 비영리 예외 분기 FALSE |
| 12 | 경기도 외 사업장 + 비영리 허용 유형 | 지역 조건 FALSE |

사례 4·5는 입주 이력을 **기관별로** 평가해야 한다. 사례 7·8은 후속 의무를 신청 당시 조건으로 소급하지 않는다. 별도 원문에 있는 추가 자격이나 법령 준용 제외 기준을 이 명세가 해결하지는 않는다.
