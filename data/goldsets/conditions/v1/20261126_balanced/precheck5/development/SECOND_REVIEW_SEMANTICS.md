# 2차 의미 검수 보고서

모든 내용은 5건의 미승인 정답 **초안**이다. 입력 `source_text`는 발췌문이며 완전성은 `UNKNOWN`이다.

## 연산자와 유형

공통 스키마는 `EQ`, `EXISTS`, `NOT_EXISTS`, `IN`, `BETWEEN`을 허용하고, `IN`의 배열 값과 `BETWEEN`의 포함 경계를 검사한다. 현재 저장소에는 지원자 사실을 입력받아 이 연산자들의 참·거짓을 계산하는 판정 엔진이 없다. 아래 진리 의미는 앞으로 필요한 판정 명세이며, 스키마 검증만으로 보장되지 않는다.

| 연산자/유형 | 필요한 의미 | 이번 초안의 처리 |
|---|---|---|
| `EQ` | 지원자 속성과 기준값의 동등성 | 연령·지역·법인 유형·등록 완료 및 제한 대상 보육센터 이력 수에 사용 |
| `EXISTS` / `NOT_EXISTS` | 대상 사실의 존재 / 부재 | 정성 요건 충족 여부에 사용하지 않음 |
| `IN` | 입력값이 명시된 집합의 원소 | 세부 기술 범위가 미수집되어 `176813`의 범위 조건에서 사용 중지 |
| `BETWEEN` | 하한·상한 및 양쪽 포함 여부 | `178507`의 19–45세에 포함 경계 객체를 유지 |
| `ELIGIBILITY = TRUE` | 해당 자격 조건의 충족 | 값이나 판정 기준을 확인할 수 없으면 `UNKNOWN`에 해당하며 `decision_possible=false` |
| `EXCLUSION = TRUE` | 해당 제외 사유에 해당 | 중복입주 여부를 `EQ true` 방향으로 기록. 적용 시점/시설 범위가 모호한 경우 판정 비허용 |

`UNKNOWN`은 이 gold-review 스키마에서 조건의 판정 결과값이 아니다. 현재는 `decision_possible=false`, null 연산자/값, `review_comment`, 미확정 관계로 한계를 보존한다. 조건의 존재와 충족을 혼동하지 않도록 정성 조건의 `EXISTS true`를 제거했다.

평가기의 FULL 매칭은 조건 유형, 카테고리, 속성, 연산자, 값·타입, 단위, 기준일 유형·값, 적용 범위와 근거 필드·span이 모두 일치해야 한다. 의미나 근거가 일부만 맞는 PARTIAL은 TP로 집계되지 않는다. 이번 5건은 미승인 상태이므로 성능 점수를 산출하지 않는다.

신청자 유형의 기존 후보는 `BUSINESS_TYPE` 필드를 사용한다. 골드 초안의 예비창업자·창업기업 유형도 `category=BUSINESS_TYPE`, `field=BUSINESS_TYPE`으로 맞췄다. `APPLICANT_TYPE`이라는 별도 필드명은 기존 평가기의 엄격 비교에서 다르게 취급되므로 사용하지 않는다.

## 기존 스키마로 해결한 것

- AND/OR 중첩, 조건 유형별 별도 루트, `BETWEEN` 포함 경계, `EQ` 방향, 개별 조건의 `decision_possible=false`.
- 8개 법인 유형별 EQ 값과 제한된 3개 유형의 비영리 분기.
- 원문 안의 조건·예외 근거 span 및 gold ID 참조.

## 구조적 한계

- AST 루트에 신청/선정/입주 이후 단계와 `ELIGIBILITY`/`EXCLUSION` 유형을 표시하는 필드가 없다. `178507`은 서로 다른 루트와 자연어 적용 범위로 구분했지만, 이 배열 자체를 판정 엔진에 그대로 투입할 수 없다.
- 예외의 `applies_to_gold_ids`는 대상 연결만 표현한다. 지방센터 경험을 계산에서 빼는 효과나 기존 영리 요건을 완화하는 변환 규칙은 나타내지 못한다. `118182`은 명시적 OR AST로 완화 효과를 보존했다.
- 제목과 본문, 업력 문장과 2019-07-08 각주처럼 복수 필드/구간에 걸친 근거를 한 gold condition의 구조적 근거 목록으로 담을 수 없다.
- 신청일·입주개시일·계약체결일 기준 상대 기한, `UNKNOWN` 진리값 및 무제한 지역 범위에는 별도의 판정 모델이 필요하다.
