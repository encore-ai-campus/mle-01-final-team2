# 개선 우선순위

영향 건수는 진단에서 관측한 오류 수이며 예상 TP 증가가 아니다. 주원인별 FN은 상호 배타적이나 부원인은 중복된다. 추가 API 예산은 0회다.

| 순서 | 개선 작업 | 관측 영향 | 비용 | 기존 응답 재사용 / 새 API |
|---|---|---|---|---|
| 1 | 공통 field/category 의미 계약 정리와 안전한 alias 범위 확정 | 속성 분류 차이 FN 15, 미지원 FN 9, 의미 보류 1 | 중~상 | 표기만 같은 명확한 alias는 오프라인 검토 가능. BUSINESS_TYPE↔APPLICANT_TYPE, 영리/사업체/지원상태 구분은 전역 alias 금지. 신규 개념과 카탈로그 확장은 사람 검수 필요 |
| 2 | 값·단위·범위 표현의 명시적 정규화와 구조화 출력 계약 | 값/단위 FN 10; 스키마 거절 FN 10 | 중 | 년/YEAR, %/PERCENT와 값 배율·경계 구조는 원문 검증을 유지한 별도 재처리 후보. UNKNOWN enum 응답은 현재 실패 유지. 향후 스키마 강제 출력/프롬프트 개선은 새 응답 필요 |
| 3 | 조건 단위와 최소 근거 구절의 일관된 출력 계약 | 부분 일치 16 중 span 차이 14; 분해 FN 8 | 중~상 | 원문 기반의 보조 진단은 오프라인 가능. 골든 span을 보고 자르는 보정 금지. 조건 분해·분기 scope·최소 근거 생성 개선은 새 응답과 사람 검수 필요 |
| 별도 선행 검증 | 논리 평가 adapter의 그룹 root·예외·미해결 관계 연결 | 그룹 0/24, AST 0/10 및 예외 미측정 | 중 | 기존 응답으로 연동 검증 가능. 조건 strict F1 개선과 구분. evaluator 변경 시 기존 결과와 버전 분리 |

## A. 추가 API 없이 검토 가능한 범위

- 176001의 년→YEAR, %→PERCENT 두 부분 일치는 현재 unit만 완전 일치를 막는다. 안전한 단위 규칙으로 재처리할 근거가 가장 명확하다. 이번에는 수정·재채점하지 않았다.
- 대구시/대구광역시, 「상법」상 회사/상법상 회사 등 표기 차이는 정규화 후보이나 span 차이도 남는다. 도내→경기도는 추가 문맥 근거 없이 바꾸지 않는다.
- 3억원의 300000000 KRW 변환은 금액 배율 정규화 가능성이 있으나 REVENUE_FINANCIAL↔REVENUE 개념 매핑도 해결해야 한다.
- BETWEEN 키 구조 통일은 경계 포함 여부·값·단위·대상 역할을 유지하는 경우만 검토한다. 대표자/팀원의 결합은 별도 문제다.
- logic_proposals에 보존된 그룹·예외·관계와 평가 adapter를 연결해 진단하는 것은 추가 API 없이 가능하다. 기존 실패를 임의 PASS로 만들지 않는다.

## B. 새 응답 또는 추출 설계 개선이 필요한 범위

- IP 권리 국가/유효성/종류/보유와 의무 내용/개수/서류 등 조건 분해 개선.
- 179386의 eligibility/preference 오분류, 178507의 LT/LTE 경계, 예비창업자와 기업의 대안 표현 등 의미 개선.
- prompt의 UNKNOWN 안내와 operator enum, 속성 정의 설명, 구조화 출력 모드 정합성. 현재 파일럿 결과를 유지한 차기 실험으로 수행한다.
- 118182 비영리 지원이 별도 조건 대신 예외로 표현된 사례의 분해/예외 설계.

## C. 사람 검수

신청자/사업체 유형, 우선지원대상기업/영리 여부, 신규 HIRE/IP/COMPLIANCE/SOGANG 개념, 177447의 관련 증빙서류 대응은 표준 속성의 의미를 먼저 합의해야 한다. 부분 일치라는 이유만으로 동등하다고 확정하지 않는다.

## 규칙과의 상호 보완

규칙 v1과 E가 맞힌 정답 ID 집합은 같은 6개다. LLM exact 1개는 다른 정답이다. 교집합 0, 규칙만 6, LLM만 1, 모두 놓침 55다. 후보 합집합의 oracle coverage는 7/62이지만 실제 hybrid Precision/F1을 뜻하지 않는다. 지원 근거 없이 합치면 FP와 중복·논리 충돌이 늘 수 있으므로 이번에는 하이브리드를 구현하지 않았다.

## 출처·유형별 해석

BIZINFO는 정답 35개 모두 FN이며, 속성 분류 12·미지원 4·분해 8·값 7·span 3·모호성 1이다. KSTARTUP은 정답 27개 중 26개 FN이며 스키마 거절 10, 미지원 5, 값 3, 속성 3, span 3, 유형 1, 미확정 1이다. 출처 차이는 178507 전체 거절과 공고별 카탈로그·조건 구성 차이를 함께 반영한다.

자격 FN 55, 제외 FN 3, 우대 FN 3이다. 제외 3개는 모두 스키마 거절된 178507에 있어 정상 출력 0개이며, 우대는 176813 미지원 2개와 179386 span 1개다. 이를 모든 제외/우대 추출 능력의 일반적 결론으로 확대하지 않는다.
