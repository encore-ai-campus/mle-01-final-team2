# Legacy 후보 활용 실험 결과

작성일: 2026-11-26  
실험 모드: `legacy_augmented` / 입력 데이터 v1 / 조건 스키마 v1.0 추출 출력

## 요약

Legacy 후보 650건을 검사해 유효한 조건 제안 30건을 추가하고 규칙 후보와 겹치는 26건을 병합했다. 의미나 근거를 안전하게 확인할 수 없는 594건은 보류·거절했다. 확정 개발 골든 30건에서 strict TP는 늘지 않았고, FP가 7건 늘어 Precision과 F1이 하락했다. 기존 Legacy 미활용 FN 40건 중 strict 평가에서 해결된 것은 0건이다. 따라서 이 모드는 기본 경로에 채택하지 않고 별도 실험 기능으로 유지한다.

## 기준선 무결성

`failure_analysis.csv`의 현재 해시는 manifest 기대값과 불일치했다. 동일한 고정 골든·예측·평가기 입력으로 재평가한 점수는 기준선과 같았다(TP 10 / FP 36 / FN 106, F1 12.3457%). CSV의 행 집합과 유형별 수는 같지만 진단 필드 값은 다르므로 불일치는 순수 직렬화 차이가 아니다. 원래 행별 진단 변경 시점과 행위자는 확인하지 못했다. 자세한 해시와 비교는 [BASELINE_INTEGRITY_DIAGNOSTIC.md](BASELINE_INTEGRITY_DIAGNOSTIC.md)에 기록했다.

## Legacy 후보 처리

| 처리 | 건수 |
|---|---:|
| 검토 후보 | 650 |
| 유효성 검증을 통과한 신규 제안 | 30 |
| 기존 규칙과 중복되어 병합 | 26 |
| 보류 또는 거절 | 594 |

보류 사유: 신청 범위 3, 미지원 속성 165, 조건 극성 불명 135, 근거가 입력에 없음 190, 위치 불일치 3, 지역 적용 범위 불명 46, 원문 사실 충돌 35, 원문 사실 불일치 17. 원문 문자열/위치 검증 통과는 의미 검수 완료를 뜻하지 않는다.

구현은 기존 추출기와 분리된 선택 실행기다. 고정 개발용 80건의 v1 조건 입력과 레거시 후보만 읽으며 GOLD ID/값/alignment, 독립 평가 데이터 및 v2 후보는 사용하지 않는다. 채택 결과는 미검수 상태이고 `decision_eligible=false`를 유지한다. 지역, 인증, 법령, 제외 및 우대 등 안전하게 제한할 수 없는 의미 유형은 채택하지 않고 보류한다.

## Strict 개발 골든 결과

평가 분모와 정책은 고정 v1.1 baseline과 같고, 30개 골든 공고만 점수화했다.

| 지표 | Baseline v1 | Legacy 활용 | 변화 |
|---|---:|---:|---:|
| TP | 10 | 10 | 0 |
| FP | 36 | 43 | +7 |
| FN | 106 | 106 | 0 |
| Precision | 21.7391% | 18.8679% | -2.8712%p |
| Recall | 8.6207% | 8.6207% | 0.0000%p |
| F1 | 12.3457% | 11.8343% | -0.5114%p |
| Macro F1 | 10.3492% | 9.5293% | -0.8199%p |
| 무예측 공고 | 8 | 6 | -2 |
| Partial Match | 18 | 20 | +2 |

기존 정확 일치 10건은 모두 유지했다. 추가된 예측은 기존 FP 0건을 해소하지 못했고, 신규 FP 7건은 strict 속성/값/근거 매칭을 만족하지 못했다. 무예측 공고 수가 줄었지만 정답 조건을 엄격하게 맞춘 추가 성공은 없었다. 안전 오류 목록은 두 결과 모두 비어 있었으며, 이는 조건 적격성의 의미 안전성 보증을 의미하지 않는다.

추가된 strict FP는 `KSTARTUP:177292`, `KSTARTUP:177857`, `KSTARTUP:176387`, `BIZINFO:126490`, `KSTARTUP:176813`, `KSTARTUP:179386`, `KSTARTUP:177469`에서 관측되었다. 조건 값·속성·근거 범위가 원문상 더 넓은 문맥을 요구하는 사례를 포함한다.

출처별 F1은 BIZINFO 7.7922%→7.6923%, K-Startup 16.4706%→15.3846%였다. 예외 3건과 우대 3건의 표본은 작으므로 해당 유형 결과를 일반화하지 않는다.

## 논리 변환기 보조 진단

기존 논리 변환기를 수정하지 않고 증강된 조건에 적용했다. AST 정확 일치 공고는 1/30으로 같았지만 그룹 F1은 3.4483%→0%, 관계 간선 F1은 2.5974%→0%였다. 조건 ID/alignment 변화가 논리 비교에도 영향을 주는 보조 진단값이며, 논리 변환기 단독 성능으로 해석하지 않는다.

## 검증 및 재현성

- 신규 합성 단위 테스트 18개 통과.
- 전체 회귀: `unittest discover -s tests -v` 결과 168개 실행, 140개 통과, 28개 건너뜀, 실패 0건.
- 조건 스키마 오류 0건, VERIFIED 0건, `decision_eligible=true` 0건.
- 독립 평가용 20건·v2 데이터·외부 LLM 호출을 사용하지 않았다.
- 증강 예측 파일을 두 독립 출력 경로에 재생성했고 파일 해시가 일치했다. 주요 SHA-256은 manifest에 기록한다.
- 기존 추출 및 논리 기준선, 고정 골든셋, baseline_v1 manifest 및 CSV는 덮어쓰지 않았다.

## 권고

현재 구현은 기본 추출 경로에 채택하지 않는다. 다음 개선은 이 실험에서 보류한 594건 중 단순 규칙 확대부터 시도하기보다, 근거가 입력에 없는 190건과 원문 사실 충돌/불일치 52건의 데이터 provenance 문제를 먼저 조사하고, 후보 분류·문맥 적용 범위를 검증할 범용 규칙을 좁은 합성 테스트로 검증하는 순서를 권한다. 이후 동일한 strict 골든 기준으로 재평가하되 기준선과 골든은 변경하지 않는다.

상세 기계 판독 점수는 `evaluation_summary.json`, 처리 근거는 `data/condition_inputs/v1/20261125/extracted/legacy_augmented/`에 있다.
